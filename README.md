# Evabeat Codex Pet

Evabeat is a custom Codex desktop pet: a tiny vinyl-and-microphone stage sprite with copper curls, teal trousers, a black jacket, and a skeptical-but-sweet coding companion energy.

## Files

- `pet.json` - Codex pet manifest
- `spritesheet.webp` - animated pet atlas
- `qa/contact-sheet.png` - visual QA contact sheet
- `qa/validation.json` - atlas validation output

## Install

Copy `pet.json` and `spritesheet.webp` into:

```text
~/.codex/pets/evabeat/
```

The pet is already installed locally on this machine at that path.
